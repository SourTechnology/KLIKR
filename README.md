# KLIKR

KLIKR is a simple browser-based clicker game. Click to earn points, then spend them on upgrades to increase your clicks or earn points automatically.

## Features

- Click to earn points
- Upgrade clicks per press
- Buy Auto-KLIKR for points per second
- Save progress in your browser
- Reset your game

## Run locally

1. Save the game code as `index.html`.
2. Open `index.html` in a web browser.

No installation or build step is required.

## Saving

KLIKR stores progress in your browser’s `localStorage`. Saved progress is specific to that browser and device.

## Technologies

- HTML
- CSS
- JavaScript

The game is a single-file prototype. TypeScript would require a build step before it can run in a browser.

## Note

This is a demo game. Progress may be lost if you clear your browser’s site data.
